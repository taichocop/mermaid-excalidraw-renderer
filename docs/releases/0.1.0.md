Initial release of Mermaid Excalidraw Renderer.

Write a `mermaid-excalidraw` block in a note and open Reading view. Flowchart and Sequence use hand-drawn Excalidraw elements; Class, ER, State and other supported types currently use SVG fallback. Includes Light/Dark contrast, font size/roughness, canvas height/padding, pan/zoom, automatic fitting and safe inline errors.

Requires Obsidian 1.13.7 or newer on desktop. Mobile is untested and unsupported in this release. No Excalidraw plugin is required.

For manual installation, download main.js, manifest.json and styles.css from this release into your vault's configuration-folder/plugins/mermaid-excalidraw-renderer directory, restart Obsidian and enable the plugin. Source archives are not installable builds. Additional license notices and SHA256SUMS.txt are attached; notices are embedded in main.js as well.

Limitations: view-only; no export; SVG fallback is not hand-drawn and may not honor all appearance settings. Complex diagrams can consume substantial memory/CPU. Normal rendering is offline; Mermaid source that references remote images or CSS can request external resources. Read README.md and SECURITY.md before rendering untrusted content.

Community Directory approval is a separate step; this release does not itself mean the plugin is listed.
